
# Design and Analysis of Algorithms I - Final Project

## Overview
This repository contains the final project for the INF05027 - Design and Analysis of Algorithms I course at the Federal University of Rio Grande do Sul (UFRGS). The main objective is to consolidate the concepts of greedy algorithms by implementing and analyzing them to solve classic graph problems.

## Addressed Problems
The project features solutions for two specific problems from the Beecrowd competitive programming platform:
* **Beecrowd 1799:** The Rat in a Maze
* **Beecrowd 1128:** Come and Go

## Repository Contents
* **Source Code:** Algorithm implementations in [Insert Language, e.g., C / Python]. The code is properly commented to explain the logic and decisions made.
* **Technical Report:** A comprehensive PDF document that includes:
    * Brief problem descriptions.
    * Solution strategies, detailing the main algorithm idea and data structures used.
    * Formal arguments of correctness, proving why the algorithms produce valid solutions.
    * Detailed time and memory complexity analyses, referenced to the code.
    * Discussion of challenges faced, alternatives considered, and learnings.
* **Beecrowd Feedback:** Screenshots proving the solutions were successfully accepted by the judge system.
